# Use Cases

Complete setups for specific scenarios, combining recommended applications, configurations, and instructions. Everything is **privacy-conscious by default** unless explicitly stated otherwise.

## Available Use Cases

- **[Office Work](./office-work/)** – Recommended setup for daily office tasks (productivity apps, email, documentation)
- **[Development](./development/)** – Recommended setup for software development *(may contain technical content)*

## Structure of Each Use Case

Each use case folder contains:
- `README.md` – Why this setup exists and who it's for
- `apps.md` – List of recommended applications (with links to [`../apps/`](../apps/))
- `setup.md` – Configuration instructions and specific settings

## Notes

- Use cases provide **end-to-end recommendations** for a specific purpose
- They may reference and combine content from the [`apps/`](../apps/) section
- Technical depth varies by audience (office work = accessible, development = may be technical)
