# Development: Recommended Applications

List of applications for a complete development setup on Zorin OS. See [`../../apps/`](../../apps/) for detailed information about each application.

## IDEs & Code Editors

- **[VSCodium](../../apps/development/VSCodium.md)** – Powerful, customizable code editor with telemetry disabled
- **[Builder](../../apps/development/Builder.md)** – GNOME IDE for developing GNOME and GTK applications
- **[Ptyxis](../../apps/development/Ptyxis.md)** – Modern, terminal-based text editor
- **[Terminal](../../apps/development/Terminal.md)** – Default GNOME terminal emulator for command-line access

## Version Control

- **[Git Cola](../../apps/development/Git Cola.md)** – Powerful Git GUI for managing repositories

## Development Tools

- **[Terminal](../../apps/development/Terminal.md)** – Essential for command-line development tasks
- **[GNOME Tweaks](../../apps/utilities/GNOME Tweaks.md)** – Customize GNOME desktop for development workflows

## Optional Add-ons

- **[Signal Desktop](../../apps/productivity/Signal Desktop.md)** – For secure team communication
- **[Obsidian](../../apps/productivity/Obsidian.md)** – For development documentation and notes
