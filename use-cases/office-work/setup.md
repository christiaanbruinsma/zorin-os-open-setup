# Office Work: Setup Instructions

Step-by-step guide to configure your Zorin OS system for office work.

## Initial Setup

1. **Install Core Applications**
   - Install OnlyOffice or LibreOffice for document editing
   - Install Evolution or Thunderbird for email management
   - Install your preferred web browser (Firefox, Chromium, or Brave)

2. **Set Default Applications**
   - Go to Zorin OS Settings > Default Applications
   - Set your preferred office suite as default for documents
   - Set your preferred email client as default for mailto links

3. **Configure Online Accounts**
   - Go to Zorin OS Settings > Online Accounts
   - Add your email accounts (Google, Microsoft, etc.) for calendar and contacts integration

## Application Configuration

### Email Client Setup
- **Evolution**: Configure your email accounts, calendar, and contacts in one place
- **Thunderbird**: Set up multiple email accounts and configure calendar add-ons
- Enable calendar synchronization with your preferred service

### Document Workflow
- **OnlyOffice**: Connect to cloud storage (Nextcloud, Dropbox, Google Drive) for seamless document access
- **Apostrophe/Obsidian**: Set up a notes directory and configure synchronization if needed
- Configure default save locations for easy access

### Communication Tools
- **Telegram/Signal**: Set up notifications and configure privacy settings
- **Ferdium**: Add your messaging services (WhatsApp, Telegram, Slack, etc.)
- **Zoom**: Test your camera and microphone before important meetings

## Organization Tips

1. **Password Management**
   - Use Passwords and Keys (Seahorse) for storing application passwords
   - Consider Proton Pass for end-to-end encrypted password management

2. **Calendar Integration**
   - Sync Evolution or Thunderbird calendar with your online accounts
   - Set up reminders for important meetings
   - Use the default GNOME Calendar for quick access

3. **Font Management**
   - Use the Fonts application to install additional fonts for documents
   - Install Microsoft Core Fonts if needed for compatibility: `sudo apt install ttf-mscorefonts-installer`

## Optimization Tips

- **Browser Choice**: Use Firefox for privacy or Chromium/Chrome for compatibility with web apps
- **Performance**: Close unnecessary applications during video calls (Zoom, Signal)
- **Backup**: Regularly back up your documents and emails using Pika Backup or similar tools
- **Updates**: Keep all office applications updated for security and new features

## Troubleshooting

- If OnlyOffice doesn't open files: Install additional font packages
- If Evolution doesn't connect: Check your email provider's IMAP/SMTP settings
- If video calls have poor quality: Check your internet connection and close background apps
