# System & Maintenance: Recommended Applications

List of applications for system administration, monitoring, and maintenance on Zorin OS. See [`../../apps/`](../../apps/) for detailed information about each application.

## System Customization

- **[GNOME Tweaks](../../apps/utilities/GNOME Tweaks.md)** – Customize advanced GNOME settings not available in standard Settings
- **[Terminal](../../apps/development/Terminal.md)** – Default GNOME terminal emulator for command-line access

## System Monitoring & Logs

- **[Logs](../../apps/utilities/Logs.md)** – View detailed event logs for your system (systemd journal)
- **[Mission Center](../../apps/utilities/Mission Center.md)** – Monitor system resources (CPU, memory, disk, network)

## Storage & Disks

- **[Disks](../../apps/utilities/Disks.md)** – Manage disks, partitions, and filesystem mount options
- **[Disk Usage Analyzer](../../apps/utilities/Disk Usage Analyzer.md)** – Analyze disk usage with visual representations
- **[File Roller](../../apps/utilities/File Roller.md)** – Archive manager for creating and extracting compressed files

## Hardware & Peripherals

- **[Camera](../../apps/utilities/Camera.md)** – Default GNOME webcam application
- **[Clocks](../../apps/utilities/Clocks.md)** – World clocks, alarms, and stopwatch
- **[Characters](../../apps/utilities/Characters.md)** – Special character map for inserting symbols

## Security & Privacy

- **[Firewall Configuration](Firewall%20Configuration.md)** – Easy and intuitive firewall management for Linux
- **[Passwords and Keys](../../apps/utilities/Passwords and Keys.md)** – Manage PGP keys and passwords (Seahorse)
- **[Proton Pass](../../apps/utilities/Proton Pass.md)** – End-to-end encrypted password manager

## Utilities

- **[Calculator](../../apps/utilities/Calculator.md)** – Default GNOME calculator with scientific modes
- **[Text Editor](../../apps/utilities/Text Editor.md)** – Simple text editor (Gedit) for quick edits
- **[Weather](../../apps/utilities/Weather.md)** – Monitor weather conditions and forecasts

## Backup & File Management

- **[Pika Backup](../../apps/utilities/Pika Backup.md)** – Simple backup utility for important files
- **[File Roller](../../apps/utilities/File Roller.md)** – Create and extract archive files

## Optional Add-ons

- **[LocalSend](../../apps/utilities/LocalSend.md)** – Secure file sharing over local network
- **[Warp](../../apps/utilities/Warp.md)** – Fast and secure file transfer between devices
- **[FileZilla](../../apps/utilities/FileZilla.md)** – FTP, FTPS, and SFTP client for remote file transfers

---
*For detailed information about each application, see the individual app pages in the [`../../apps/`](../../apps/) directory.*
