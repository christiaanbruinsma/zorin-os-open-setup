# File Auditor

**Category:** Open Business Tools → Files & Insight<br><br>
**Website:** https://github.com/christiaanbruinsma/file-auditor

Inspect file identity, metadata and privacy signals, then verify integrity locally. Examine files for security and privacy information.

## Key Features
- Inspect file identity and metadata
- Check privacy signals
- Verify file integrity with checksums
- Local analysis without external services

## How to Get It
File Auditor is available on GitHub. Download the latest release from the project page.

[Download File Auditor](https://github.com/christiaanbruinsma/file-auditor)

## Privacy & Notes
- Local-first application, no account or online service required
- Open source software
- All file analysis happens on your local machine
