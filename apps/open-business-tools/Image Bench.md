# Image Bench

**Category:** Open Business Tools → Everyday Work<br><br>
**Website:** https://github.com/christiaanbruinsma/image-bench

Resize, compare and optimize batches of JPEG and PNG images locally. Process multiple images efficiently without uploading to external services.

## Key Features
- Batch resize JPEG and PNG images
- Compare images before and after processing
- Local optimization without quality loss
- Bulk processing capabilities

## How to Get It
Image Bench is available on GitHub. Download the latest release from the project page.

[Download Image Bench](https://github.com/christiaanbruinsma/image-bench)

## Privacy & Notes
- Local-first application, no account or online service required
- Open source software
- All image processing happens on your local machine
