# Data Inspector

**Category:** Open Business Tools → Files & Insight<br>
**Website:** https://github.com/christiaanbruinsma/data-inspector

Inspect JSON, CSV and TSV data locally in structured and raw views without rewriting the source. Analyze data files with ease.

## Key Features
- Inspect JSON, CSV and TSV files
- Structured and raw data views
- Local analysis without modifying source files
- Support for common data formats

## How to Get It
Data Inspector is available on GitHub. Download the latest release from the project page.

[Download Data Inspector](https://github.com/christiaanbruinsma/data-inspector)

## Privacy & Notes
- Local-first application, no account or online service required
- Open source software
- All data analysis happens on your local machine
