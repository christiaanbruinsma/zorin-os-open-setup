# Snippet Manager

**Category:** Open Business Tools → Everyday Work<br>
**Website:** https://github.com/christiaanbruinsma/snippet-manager

Organize and reuse replies, business details, code fragments and other frequently used text. Save time by quickly inserting pre-defined text snippets.

## Key Features
- Organize text snippets in categories
- Quick search and insertion
- Support for business details and replies
- Code fragment management

## How to Get It
Snippet Manager is available on GitHub. Download the latest release from the project page.

[Download Snippet Manager](https://github.com/christiaanbruinsma/snippet-manager)

## Privacy & Notes
- Local-first application, no account or online service required
- Open source software
- All snippet data remains on your local machine
