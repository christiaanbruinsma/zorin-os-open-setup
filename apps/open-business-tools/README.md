# Open Business Tools

Open-source desktop applications for everyday work, designed with the practical needs of small businesses in mind. All applications are available on GitHub and can be installed manually.

## Categories

### Workspace & Delivery
- [Workspace Hub](./Workspace%20Hub.md) - A clear starting point for applications, web apps, files, shared locations and daily tools.
- [Delivery Hub](./Delivery%20Hub.md) - Prepare and verify delivery packages with manifests, checksums and structured ZIP exports.

### Everyday Work
- [Image Bench](./Image%20Bench.md) - Resize, compare and optimize batches of JPEG and PNG images locally.
- [PDF Workbench](./PDF%20Workbench.md) - Preview, organize, merge, rotate, extract and split PDF pages while keeping source files untouched.
- [Snippet Manager](./Snippet%20Manager.md) - Organize and reuse replies, business details, code fragments and other frequently used text.
- [QR Generator](./QR%20Generator.md) - Create and export QR codes locally as PNG or SVG without accounts, tracking or history.
- [Text Cleaner](./Text%20Cleaner.md) - Inspect and clean text copied from websites, AI tools, email and office documents.

### Files & Insight
- [File Auditor](./File%20Auditor.md) - Inspect file identity, metadata and privacy signals, then verify integrity locally.
- [Data Inspector](./Data%20Inspector.md) - Inspect JSON, CSV and TSV data locally in structured and raw views without rewriting the source.

### Development Tools
- [Git Desk](./Git%20Desk.md) - A user-friendly Git client with all basic Git features plus a built-in Git Guide.
