# Git Desk

**Category:** Open Business Tools → Development Tools
**Website:** https://github.com/christiaanbruinsma/git-desk

Easy to start. Powerful enough to stay. A user-friendly Git client with all basic Git features plus a built-in Git Guide.

## Key Features
- Intuitive UI for Git operations
- All basic Git features included
- Built-in Git Guide for reference
- Local-first, no external services required

## How to Get It
Git Desk is available on GitHub. Download the latest release from the project page.

[Download Git Desk](https://github.com/christiaanbruinsma/git-desk)

## Privacy & Notes
- Local-first application, no account or online service required
- Open source software
- All data remains on your local machine
