# PDF Workbench

**Category:** Open Business Tools → Everyday Work<br><br>
**Website:** https://github.com/christiaanbruinsma/pdf-workbench

Preview, organize, merge, rotate, extract and split PDF pages while keeping source files untouched. Comprehensive PDF management tool.

## Key Features
- Preview PDF documents
- Organize and reorder pages
- Merge multiple PDF files
- Rotate, extract and split pages
- Non-destructive editing of source files

## How to Get It
PDF Workbench is available on GitHub. Download the latest release from the project page.

[Download PDF Workbench](https://github.com/christiaanbruinsma/pdf-workbench)

## Privacy & Notes
- Local-first application, no account or online service required
- Open source software
- All PDF processing happens on your local machine
