# Inkscape

**Category:** Creativity → Vector Graphics<br>
**Website:** [https://inkscape.org/](https://inkscape.org/)

Use this app for professional vector graphics creation. Inkscape is a professional quality vector graphics software used by design professionals and hobbyists worldwide for creating a wide variety of graphics such as illustrations, icons, logos, diagrams, maps, and web graphics.

## Key Features
- Professional quality vector graphics software
- Native support for SVG (Scalable Vector Graphics) - the W3C open standard
- Create various graphics: illustrations, icons, logos, diagrams, maps, web graphics
- Cross-platform support (Windows, macOS, Linux)
- Extensible with plugins and extensions
- Advanced drawing tools (bezier curves, shapes, text)
- Object manipulation and transformation
- Color management and gradients
- Layers and groups for complex compositions
- Import and export various file formats
