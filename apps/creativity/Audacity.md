# Audacity

**Category:** Creativity → Audio Editor<br><br>
**Website:** [https://www.audacityteam.org/](https://www.audacityteam.org/)

Use this app to record and edit audio. Audacity is the world's most popular free, easy-to-use, multi-track audio editor and recorder for creating music, podcasts, and other audio content.

## Key Features
- Cross-platform audio editor for Windows, macOS, and Linux
- Record, clean up, enhance, and produce audio
- Advanced voice editing tools
- Plugin support for VST3 and Nyquist plugins
- Import and export various audio formats (WAV, MP3, FLAC, Ogg, etc.)

## How to Get It
Audacity is available in the Zorin OS Software app and can also be downloaded from the official website.

[Download Audacity](https://www.audacityteam.org/)
