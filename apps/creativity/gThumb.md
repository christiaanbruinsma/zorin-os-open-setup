# gThumb

**Category:** Creativity → Image Viewer
**Website:** [https://wiki.gnome.org/Apps/gThumb](https://wiki.gnome.org/Apps/gThumb)

Use this app to view and manage your image files. gThumb is a lightweight image viewer with basic editing capabilities.

## Key Features
- Lightweight and fast image viewer
- Supports various image formats (JPEG, PNG, GIF, etc.)
- Basic editing tools (rotate, crop, resize)
- Slideshow mode
- File management (copy, move, delete)

## How to Get It
gThumb is available in the Zorin OS Software app and can also be downloaded from the official website.

[Download gThumb](https://wiki.gnome.org/Apps/gThumb)

## Privacy & Notes
- Open-source application
- Local only, no cloud dependency
