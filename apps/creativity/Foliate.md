# Foliate

**Category:** Creativity → E-Book Reader<br>
**Website:** [https://github.com/johnfactotum/foliate](https://github.com/johnfactotum/foliate)

Use this app to read e-books in style. Foliate is a simple and modern GTK eBook reader that supports various eBook formats with a clean, user-friendly interface.

## Key Features
- Read e-books in a modern, styled interface
- Supports multiple eBook formats (EPUB, MOBI, AZW, AZW3, CBZ, FB2, PDF, and more)
- Dark mode support
- Wikipedia lookup for quick information
- View and edit book metadata
- Annotation capabilities
- Popup footnotes
- Supports vertical writing
- Text-to-speech support (with speech-dispatcher)
- Auto-hyphenation support

## How to Get It
