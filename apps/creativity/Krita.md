# Krita

**Category:** Creativity → Digital Painting<br><br>
**Website:** [https://krita.org/en/](https://krita.org/en/)

Use this app for professional digital painting. Krita is a professional free and open-source painting program made by artists that want to see affordable art tools for everyone, offering a comprehensive suite of tools for digital artists.

## Key Features
- Clean and flexible interface with customizable layout and 30+ dockers
- Over 100 professionally made brushes preloaded
- Brush stabilizers (3 different smoothing methods)
- Vector and text tools with SVG support
- 9 unique brush engines with extensive customization
- Wrap-around mode for seamless textures and patterns
- Resource Manager for importing and sharing brush/texture packs
- 2D Animation with multiple layers, audio support, and thousands of frames
- Drawing assistants for vanishing points and straight lines
- Advanced layer management (vector, filter, group, file layers)
- Selection and transformation tools
- Full color management (LCMS for ICC, OpenColor IO for EXR)
- GPU enhanced performance (OpenGL, Direct3D)
- PSD file support
- HDR painting capability
- Python scripting for extending functionality
- Training resources and tutorials
