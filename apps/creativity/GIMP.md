# GIMP

**Category:** Creativity → Image Editor<br>
**Website:** [https://www.gimp.org/](https://www.gimp.org/)

Use this app as a free and open-source image editor. GIMP (GNU Image Manipulation Program) is a cross-platform image editor that provides sophisticated tools for graphic designers, photographers, illustrators, and scientists to get their work done.

## Key Features
- High quality photo manipulation (retouching, restoring, creative composites)
- Original artwork creation with power and flexibility
- Graphic design elements (icons, UI components, mockups)
- High-fidelity color management for digital and printed media
- Scripted image manipulation with multi-language support (C, C++, Python, Scheme)
- Extensible through plugins and scripts
- Cross-platform support (GNU/Linux, macOS, Windows)
- Customizable interface and workflow
- Integration with other free software (Scribus, Inkscape)

## How to Get It
