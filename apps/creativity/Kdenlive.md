# Kdenlive

**Category:** Creativity → Video Editor
**Website:** [https://kdenlive.org/](https://kdenlive.org/)

Use this app for free and open-source video editing. Kdenlive (KDE Non-Linear Video Editor) is a powerful video editor that works on Linux, Windows, macOS, and BSD, providing professional-grade editing capabilities for all skill levels.

## Key Features
- Multi-track video editing with unlimited video and audio tracks
- Support for almost any audio and video format (based on FFmpeg libraries)
- 3-point editing (industry-standard technique)
- Customizable interface with saveable layouts
- Built-in 2D Title Editor for text and credits
- Integration with Glaxnimate for vector graphics animations
- Wide range of effects and filters (artistic, stylish, blur, sharpen, color correction, audio adjustments)
- Multi-cam editing for quick angle switching
- Audio and video scopes (Meter, Histogram, Waveform, Vectorscope, RGB Parade)
- Proxy editing for smooth performance on low-end systems
- Automatic project backup with version history
- Automatic subtitle generation using VOSK and Whisper models
- Online resources (KDE Store, Pexels, Pixabay, Freesound, Internet Movie Archive)
- Timeline preview render for smooth playback
- Keyframeable effects with different interpolation types
