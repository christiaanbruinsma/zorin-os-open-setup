# Applications

Recommended applications for Zorin OS, categorized by use case. All recommendations are **privacy-conscious by default** unless explicitly stated otherwise.

## Categories

- **[Productivity](./productivity/)** – Office suites, email clients, note-taking, and calendar apps
- **[Creativity](./creativity/)** – Graphic design, video editing, audio production, and media tools
- **[Development](./development/)** – IDEs, code editors, version control, and developer tools *(technical content may apply)*
- **[Utilities](./utilities/)** – System tools, backup solutions, file managers, and productivity helpers
- **[Compatibility](./compatibility/)** – Tools for running non-Linux software (Wine, VirtualBox, etc.) and mainstream service integrations

## Selection Criteria

Applications are included based on:
- **Usability**: Intuitive and accessible for non-technical users
- **Integration**: Works well with Zorin OS and the GNOME desktop
- **Practicality**: Helps users transition from other operating systems
- **Privacy balance**: Respects privacy while maintaining functionality

## Notes

- Mainstream software (e.g., Microsoft or Google products) may be included where it aids transition
- Open-source alternatives are preferred when they meet the above criteria
- Developer-focused tools may have technical explanations
