# Terminal

**Category:** Development → Terminal<br><br>
**Website:** [https://gitlab.gnome.org/GNOME/gnome-terminal](https://gitlab.gnome.org/GNOME/gnome-terminal)

Use this app as a terminal emulator for the GNOME desktop environment. Terminal allows you to execute commands, run programs, and access the command-line interface with a user-friendly graphical window.

## Key Features
- Multiple tabs within a single window
- Customizable profiles with different fonts, colors, and behaviors
- Support for multiple color schemes (16 colors, 256-color palette, true color/RGB)
- URL and email address detection with clickable links
- Text rewrapping on window resize
- Search within terminal output
- Zoom in and out functionality
- Custom commands and shells on startup
- Save terminal contents to a file
- Fullscreen mode
- Keyboard shortcuts for efficient navigation

## How to Get It
Terminal comes installed by default on Zorin OS. It is also available in the Zorin OS Software app.

[Get Terminal](https://gitlab.gnome.org/GNOME/gnome-terminal)

## Privacy & Notes
- Open-source application
- Developed by The GNOME Project
- Originally written by Havoc Pennington
- Built on the VTE library for robust terminal emulation
