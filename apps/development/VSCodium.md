# VSCodium

**Category:** Development → Code Editor<br>
**Website:** [https://vscodium.com/](https://vscodium.com/)

Use this app to write and edit code with a powerful, customizable editor. VSCodium is a community-driven, freely-licensed binary distribution of a popular code editor with telemetry disabled by default.

## Key Features
- Full-featured code editor with syntax highlighting, IntelliSense, and debugging
- Supports extensions from the Visual Studio Code marketplace
- Lightweight and fast performance
- Highly customizable themes and settings
- Built-in terminal and Git integration

## How to Get It
VSCodium is available in the Zorin OS Software app and can also be downloaded from the official website.

[Download VSCodium](https://vscodium.com/)

## Privacy & Notes
- Open-source application (MIT licensed)
- No telemetry or tracking by default
- Compatible with Visual Studio Code extensions
