# Builder

**Category:** Development → IDE<br><br>
**Website:** [https://apps.gnome.org/Builder](https://apps.gnome.org/Builder)

Use this app to develop software for GNOME. Builder is an IDE focused on writing GNOME-based software, designed to streamline development for the GNOME platform.

## Key Features
- Specialized IDE for GNOME-based software development
- Built with C and Python for optimal performance
- Supports a wide range of language servers (Bash, C/C++, Go, Java, Python, Rust, TypeScript, Vala, Zig, and more)
- Deep integration with GNOME releases and GTK
- Built using the Meson build system

## How to Get It
Builder is available in the Zorin OS Software app and can also be downloaded from the official website.

[Get Builder](https://apps.gnome.org/Builder)

## Privacy & Notes
- Open-source application (GNU GPL v3+ licensed)
- Primarily developed for and by the GNOME community
- Language server support automatically locates servers within your build environment
