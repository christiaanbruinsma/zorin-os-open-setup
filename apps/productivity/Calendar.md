# Calendar

**Category:** Productivity → Calendar<br><br>
**Website:** [https://apps.gnome.org/Calendar/](https://apps.gnome.org/Calendar/)

Use this app to manage your schedule. Calendar is an elegant tool by The GNOME Project that helps you plan and stay on top of your schedule for upcoming days, weeks, and months.

## Key Features
- Create and manage unlimited calendars and events
- Infinite scrolling month view, week timetable, and scheduling list view
- Integrates with Evolution data server for handling large quantities of events
- Add calendars from online services (NextCloud, Google Calendar, CalDAV/WebDAV)
- Supports local and offline calendaring
- Synchronize events across multiple devices and platforms

## How to Get It
Calendar comes installed by default on Zorin OS. It is also available in the Zorin OS Software app and can be downloaded from the official website.

[Get Calendar](https://apps.gnome.org/Calendar/)
