# Apostrophe

**Category:** Productivity → Markdown Editor
**Website:** [https://apps.gnome.org/Apostrophe/](https://apps.gnome.org/Apostrophe/)

Use this app to edit Markdown in style. Apostrophe is a clean, distraction-free markdown editor by Manuel Genovés, designed to help you focus on your writing.

## Key Features
- User interface tailored to comfortable writing
- Distraction-free mode for immersive editing
- Dark, light, and sepia themes
- Standard text editor features like spellchecking and document statistics
- Live preview of Markdown content
- Export to multiple formats: PDF, Word/LibreOffice, LaTeX, and HTML slideshows

## How to Get It
Apostrophe is available in the Zorin OS Software app and can also be downloaded from the official website.

[Get Apostrophe](https://apps.gnome.org/Apostrophe/)
