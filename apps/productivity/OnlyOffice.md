# OnlyOffice

**Category:** Productivity → Office Suite
**Website:** [https://www.onlyoffice.com](https://www.onlyoffice.com)

Use this app to work on your office files such as text documents, spreadsheets, presentations, and PDF files. OnlyOffice has a nice modern interface and supports various file formats like Word and Excel.

## Key Features
- Clean, modern interface for intuitive use
- All-in-one solution for text documents, spreadsheets, and presentations
- Supports a wide range of file formats for seamless compatibility

## How to Get It
OnlyOffice is available in the Zorin OS Software app and can also be downloaded from the official website.

[Download OnlyOffice](https://www.onlyoffice.com)

## Privacy & Notes
- The desktop version runs locally without requiring cloud services or sending data to external servers.
- Supports editing PDF files directly, which is useful for annotations or form filling.
