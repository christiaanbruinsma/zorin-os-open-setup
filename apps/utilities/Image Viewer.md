# Image Viewer

**Category:** Utilities → Image Viewer
**Website:** [https://gitlab.gnome.org/GNOME/eog](https://gitlab.gnome.org/GNOME/eog)

Use this app to view and browse through images on your system. Image Viewer is the default GNOME image viewer, also known as Eye of GNOME (EOG), providing a simple and efficient way to display various image formats.

## Key Features
- View various image formats
- Browse images in a directory with thumbnail navigation
- Slide show mode for viewing multiple images
- Zoom in and out of images
- Rotate images
- Fullscreen viewing mode
- Basic image manipulation (crop, resize)

## How to Get It
Image Viewer comes installed by default on Zorin OS. It is also available in the Zorin OS Software app.

[Get Image Viewer](https://gitlab.gnome.org/GNOME/eog)
