# Disks

**Category:** Utilities → Disk Management<br><br>
**Website:** [https://apps.gnome.org/DiskUtility/](https://apps.gnome.org/DiskUtility/)

Use this app to view, modify, and configure disks and storage media. Disks by The GNOME Project provides tools for managing your storage devices, including mounting, formatting, and monitoring.

## Key Features
- View and modify disk partitions and storage media
- Configure disk settings and formatting
- Attach and mount disk images
- Disk health monitoring with SMART status notifications

## How to Get It
Disks comes installed by default on Zorin OS. It is also available in the Zorin OS Software app.

[Get Disks](https://apps.gnome.org/DiskUtility/)

## Privacy & Notes
- Open-source application
- Developed by The GNOME Project
- Default disk management tool for GNOME-based distributions
