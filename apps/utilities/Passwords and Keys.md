# Passwords and Keys

**Category:** Utilities → Security
**Website:** [https://gitlab.gnome.org/GNOME/seahorse](https://gitlab.gnome.org/GNOME/seahorse)

Use this app to create and manage PGP and SSH keys and to save passwords that are difficult to remember. Passwords and Keys provides a secure way to store passwords and manage encryption keys for secure communications and authentication.

## Key Features
- Create, manage, and use PGP keys for encrypting and signing
- Create, import, and export SSH keys for secure remote connections
- Store and manage passwords in password keyrings
- Lock and unlock keyrings for added security
- Support for HKP and LDAP key servers
- Securely back up keys
- Integrates with other GNOME applications

## How to Get It
Passwords and Keys comes installed by default on Zorin OS. It is also available in the Zorin OS Software app.

[Get Passwords and Keys](https://gitlab.gnome.org/GNOME/seahorse)

## Privacy & Notes
- Open-source application (GPL-2.0-or-later)
