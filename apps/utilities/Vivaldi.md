# Vivaldi

**Category:** Utilities → Web Browser
**Website:** [https://vivaldi.com/](https://vivaldi.com/)

Use this app as a powerful, personal, and private web browser with unmatched customization. Vivaldi is designed for users who demand more from their browser.

## Key Features
- Desktop-style tabs for efficient browsing
- Built-in ad and tracker blocker
- Secure data sync between devices with end-to-end encryption
- Built-in Mail client, Calendar, and Feed Reader
- Web Panels for quick access to frequently used sites
- Notes integrated into the sidebar
- Tab Tiling and Tab Stacking for organized workflows
- Workspaces for grouping related tabs
- Built-in screenshot capture and translation tools
- Mouse Gestures and Command Chains for advanced customization

## How to Get It
Vivaldi is available in the Zorin OS Software app and can also be downloaded from the official website.

[Download Vivaldi](https://vivaldi.com/)
