# Remmina

**Category:** Utilities → Remote Desktop<br><br>
**Website:** [https://remmina.org/](https://remmina.org/)

Use this app for remote access to other desktops and file sharing. Remmina is a free and open-source remote desktop client that supports multiple protocols.

## Key Features
- Remote desktop client with support for multiple connection protocols
- Protocol support: RDP, SSH, SPICE, VNC, X2Go, and HTTP/HTTPS
- Additional features: plugins, kiosk mode, multi-monitor support
- Available in 67 languages

## How to Get It
Remmina is available in the Zorin OS Software app and can also be downloaded from the official website.

[Download Remmina](https://remmina.org/)
