# Characters

**Category:** Utilities → Character Map
**Website:** [https://apps.gnome.org/Characters/](https://apps.gnome.org/Characters/)

Use this app to find and insert unusual characters, emoji, and symbols. Characters is a simple utility that allows you to quickly find the character you are looking for by searching for keywords or browsing by categories.

## Key Features
- Search for characters by keywords
- Browse characters by categories (Punctuation, Pictures, Math, Symbols, etc.)
- Quick insertion of special characters and emoji
- Simple and intuitive interface

## How to Get It
Characters comes installed by default on Zorin OS. It is also available in the Zorin OS Software app and can be downloaded from the official website.

[Get Characters](https://apps.gnome.org/Characters/)
