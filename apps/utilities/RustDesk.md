# RustDesk

**Category:** Utilities → Remote Desktop
**Website:** [https://rustdesk.com/](https://rustdesk.com/)

Use this app to remotely access and control other computers. RustDesk is a secure, open-source alternative for remote desktop connections, ideal for providing remote support.

## Key Features
- Remote desktop control with high performance
- File transfer between connected devices
- Built-in chat functionality
- Cross-platform support (Windows, macOS, Linux, Android, iOS)
- End-to-end encryption for secure connections

## How to Get It
RustDesk is available in the Zorin OS Software app and can also be downloaded from the official website.

[Download RustDesk](https://rustdesk.com/)

## Privacy & Notes
- Open-source application
- End-to-end encrypted connections by default
- Self-hosting option available for full control
