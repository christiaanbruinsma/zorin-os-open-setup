# Google Chrome

**Category:** Utilities → Web Browser<br><br>
**Website:** [https://www.google.com/chrome/](https://www.google.com/chrome/)

Use this app if you rely on Google Chrome for work, specific websites, or extensions that require it.

## Key Features
- Full compatibility with Chrome Web Store extensions
- Seamless sync with Google account for bookmarks, passwords, and settings
- Built-in tools like Password Manager and Safe Browsing
- Optimized for performance with memory and energy saving features

## How to Get It
Google Chrome is available in the Zorin OS Software app and can also be downloaded from the official website.

[Download Google Chrome](https://www.google.com/chrome/)

## Privacy & Notes
- Proprietary software by Google
- Collects usage statistics and crash reports by default (can be disabled in settings)
- Requires a Google account for full sync functionality
