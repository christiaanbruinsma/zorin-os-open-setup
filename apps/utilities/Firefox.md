# Firefox

**Category:** Utilities → Web Browser<br>
**Website:** [https://www.mozilla.org/en-US/firefox/](https://www.mozilla.org/en-US/firefox/)

Use this app as a fast, private browser that puts you in control. Firefox blocks trackers by default and offers features like tab groups, reader mode, and cross-device sync.

## Key Features
- Blocks trackers automatically by default
- Focus features: tab groups, reader mode, and picture-in-picture
- Control over AI features (optional by design)
- Syncs bookmarks, passwords, and history across devices
- Data encrypted by default during sync
- Supports a wide range of extensions and themes
- Built around clear privacy principles

## How to Get It
Firefox is available in the Zorin OS Software app and can also be downloaded from the official website.

[Download Firefox](https://www.mozilla.org/en-US/firefox/)
