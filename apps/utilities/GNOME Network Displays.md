# GNOME Network Displays

**Category:** Utilities → Screen Casting<br><br>
**Website:** [https://gitlab.gnome.org/GNOME/gnome-network-displays](https://gitlab.gnome.org/GNOME/gnome-network-displays)

Use this app to cast your desktop to a remote display. GNOME Network Displays allows you to stream your screen to compatible devices using wireless display technologies such as Miracast and Chromecast.

## Key Features
- Cast your desktop to a remote display
- Supports Miracast (Wi-Fi Display) protocol
- Supports Chromecast protocol
- Stream the selected monitor when available
- Experimental implementation of Wi-Fi Display
- Works with various compatible devices (TVs, wireless display adapters, etc.)

## How to Get It
GNOME Network Displays is available in the Zorin OS Software app and can also be downloaded from the official website.

[Get GNOME Network Displays](https://gitlab.gnome.org/GNOME/gnome-network-displays)
