# Clocks

**Category:** Utilities → Clock<br><br>
**Website:** [https://apps.gnome.org/Clocks/](https://apps.gnome.org/Clocks/)

Use this app to keep track of time. Clocks is a simple and elegant clock application by The GNOME Project that includes world clocks, alarms, a stopwatch, and timers.

## Key Features
- Show the time in different cities around the world
- Set alarms to wake you up
- Measure elapsed time with an accurate stopwatch
- Set timers for cooking or other tasks

## How to Get It
Clocks comes installed by default on Zorin OS. It is also available in the Zorin OS Software app and can be downloaded from the official website.

[Get Clocks](https://apps.gnome.org/Clocks/)
