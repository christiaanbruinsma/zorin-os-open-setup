# Firewall Configuration

**Category:** Utilities → Firewall
**Website:** [https://github.com/costales/gufw](https://github.com/costales/gufw)

Use this app as an easy and intuitive way to manage your Linux firewall. gufw supports common tasks such as allowing or blocking pre-configured applications, common P2P applications, or individual ports.

## Key Features
- Graphical interface for managing Linux firewall (UFW)
- Allow or block pre-configured applications
- Allow or block common P2P applications
- Allow or block individual ports
- Simple and straightforward configuration

## How to Get It
gufw comes installed by default on Zorin OS. It can also be installed from the Zorin OS Software app.

[View on GitHub](https://github.com/costales/gufw)

## Privacy & Notes
- Open-source application (GPL-3.0 licensed)
- Manages the underlying UFW (Uncomplicated Firewall) rules
- Default firewall management tool for many Linux distributions
