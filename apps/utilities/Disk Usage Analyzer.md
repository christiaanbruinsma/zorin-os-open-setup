# Disk Usage Analyzer

**Category:** Utilities → Disk Analysis
**Website:** [https://apps.gnome.org/Baobab/](https://apps.gnome.org/Baobab/)

Use this app to check folder sizes and available disk space. Disk Usage Analyzer is a simple application by The GNOME Project that helps you keep your disk usage under control.

## Key Features
- Scan specific folders, storage devices, and online accounts
- Provides both a tree and a graphical representation of folder sizes
- Makes it easy to identify where disk space is wasted

## How to Get It
Disk Usage Analyzer comes installed by default on Zorin OS. It is also available in the Zorin OS Software app.

[Get Disk Usage Analyzer](https://apps.gnome.org/Baobab/)
