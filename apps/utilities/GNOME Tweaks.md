# GNOME Tweaks

**Category:** Utilities → Customization
**Website:** [https://gitlab.gnome.org/GNOME/gnome-tweaks](https://gitlab.gnome.org/GNOME/gnome-tweaks)

Use this app to customize advanced GNOME settings not available in the standard Settings app. GNOME Tweaks provides access to additional configuration options for fine-tuning your desktop experience.

## Key Features
- Change themes, icons, and cursors
- Adjust fonts and scaling factors
- Modify window behavior (maximizing, minimizing, resizing)
- Configure workspace settings (dynamic or static creation)
- Manage startup applications
- Adjust keyboard and mouse behavior
- Toggle animations and other advanced options

## How to Get It
GNOME Tweaks is available in the Zorin OS Software app and can also be downloaded from the official website.

[Get GNOME Tweaks](https://gitlab.gnome.org/GNOME/gnome-tweaks)
