# Pika Backup

**Category:** Utilities → Backup<br>
**Website:** [https://apps.gnome.org/PikaBackup/](https://apps.gnome.org/PikaBackup/)

Use this app to keep your data safe. Pika Backup makes backups the easy way: plug in your USB drive and let Pika do the rest.

## Key Features
- Create backups locally and remotely
- Set a schedule for regular backups (from monthly to hourly)
- Save time and disk space by avoiding duplicate copies of known data
- Encrypt your backups for security
- List and browse created archives
- Recover files or folders via your file browser
- Powered by the well-tested BorgBackup software

## How to Get It
Pika Backup is available in the Zorin OS Software app and can also be downloaded from the official website.

[Get Pika Backup](https://apps.gnome.org/PikaBackup/)

## Privacy & Notes
- Open-source application (GPL-3.0 licensed)
- Designed for personal data backups, not complete system recovery
