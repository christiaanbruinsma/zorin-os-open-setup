# Weather

**Category:** Utilities → Weather<br>
**Website:** [https://apps.gnome.org/Weather/](https://apps.gnome.org/Weather/)

Use this app to monitor weather conditions and forecasts. Weather allows you to check current weather conditions for your city or anywhere in the world, with access to detailed forecasts up to 7 days, including hourly details for the current and next day.

## Key Features
- Monitor current weather conditions
- Access detailed forecasts up to 7 days
- Hourly details for the current and next day
- Uses various internet weather services
- Integrates with GNOME Shell
- View weather in Activities Overview by typing city names

## How to Get It
Weather comes installed by default on Zorin OS. It is also available in the Zorin OS Software app.

[Get Weather](https://apps.gnome.org/Weather/)
