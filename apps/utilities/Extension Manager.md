# Extension Manager

**Category:** Utilities → Extensions
**Website:** [https://github.com/mjakeman/extension-manager](https://github.com/mjakeman/extension-manager)

Use this app to browse, install, and manage GNOME Shell Extensions. Extension Manager is a native tool by Matthew Jakeman for discovering and managing extensions from extensions.gnome.org.

## Key Features
- Browse and search extensions from extensions.gnome.org
- Install and manage GNOME Shell Extensions
- Built with GTK 4 and libadwaita for a modern experience

## How to Get It
Extension Manager is available in the Zorin OS Software app and can also be downloaded from Flathub.

[Get Extension Manager on Flathub](https://flathub.org/apps/details/com.mattjakeman.ExtensionManager)
