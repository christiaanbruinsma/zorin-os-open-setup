# Brasero

**Category:** Utilities → Disc Burning<br><br>
**Website:** [https://gitlab.gnome.org/GNOME/brasero](https://gitlab.gnome.org/GNOME/brasero)

Use this app to create and copy CDs and DVDs. Brasero is a CD/DVD mastering tool for the GNOME Desktop, designed to be simple and easy to use for burning optical media.

## Key Features
- Create data CDs/DVDs with support for editing disc contents
- Burn data CDs/DVDs on the fly
- Supports multisession and Joliet extension
- Write CD-TEXT information for audio CDs
- Burn audio CDs on the fly from various audio formats (ogg, flac, mp3, etc.)
- Copy CDs/DVDs to hard drive or on the fly
- Supports single-session data DVDs and various CD types
- Can copy encrypted Video DVDs (requires libdvdcss)
- Erase CD/DVD media
- Save and load disc projects
- Burn CD/DVD images and cue files
- Preview songs, images, and videos
- Drag and drop support from file managers
- Asynchronous disc I/O to prevent application blocking

## How to Get It
Brasero comes installed by default on Zorin OS. It is also available in the Zorin OS Software app.

[Get Brasero](https://gitlab.gnome.org/GNOME/brasero)
