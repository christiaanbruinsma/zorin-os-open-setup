# Text Editor

**Category:** Utilities → Text Editor<br>
**Website:** [https://apps.gnome.org/TextEditor/](https://apps.gnome.org/TextEditor/)

Use this app to edit text files. Text Editor is a simple text editor by The GNOME Project focused on a pleasing default experience, and comes installed by default on Zorin OS.

## Key Features
- Simple and intuitive text editing
- Syntax highlighting for various file types, including code and markdown
- Clean, user-friendly interface
- Designed for a seamless default experience

## How to Get It
Text Editor comes installed by default on Zorin OS. It is also available in the Zorin OS Software app and can be downloaded from the official website.

[Get Text Editor](https://apps.gnome.org/TextEditor/)

## Privacy & Notes
- Open-source application (GPL-3.0-or-later licensed)
