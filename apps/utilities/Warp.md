# Warp

**Category:** Utilities → File Transfer<br>
**Website:** [https://apps.gnome.org/Warp/](https://apps.gnome.org/Warp/)

Use this app for fast and secure file transfer. Warp allows you to securely send files between devices via the internet or local network by exchanging a word-based code, using the Magic Wormhole protocol.

## Key Features
- Send files between multiple devices
- Every file transfer is encrypted
- Direct transfer on local network when possible
- Uses the Magic Wormhole protocol
- QR Code support
- Compatible with Magic Wormhole command line client and other compatible apps

## How to Get It
Warp is available in the Zorin OS Software app and can also be downloaded from the official website.

[Get Warp](https://apps.gnome.org/Warp/)

## Privacy & Notes
