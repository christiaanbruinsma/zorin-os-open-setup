# FileZilla

**Category:** Utilities → File Transfer<br><br>
**Website:** [https://filezilla-project.org/](https://filezilla-project.org/)

Use this app to transfer files between your computer and remote servers. FileZilla is a cross-platform FTP, FTPS, and SFTP client with an intuitive interface.

## Key Features
- Supports FTP, FTPS, and SFTP protocols
- Cross-platform compatibility
- Tabbed interface for managing multiple connections
- Site Manager for storing connection details
- Transfer queue for managing file transfers
- Resume and transfer large files (files larger than 4GB)
- Drag and drop support
- Directory comparison
- Configurable transfer speed limits
- Filename filters
- Network configuration wizard
- Remote file editing

## How to Get It
FileZilla is available in the Zorin OS Software app and can also be downloaded from the official website.

[Download FileZilla](https://filezilla-project.org/)
