# Mission Center

**Category:** Utilities → System Monitor<br><br>
**Website:** [https://missioncenter.io/](https://missioncenter.io/)

Use this app to monitor your CPU, Memory, Disk, Network, and GPU usage. Mission Center provides a comprehensive overview of your system's performance in a clean, user-friendly interface.

## Key Features
- Monitor overall or per-thread CPU usage (including processes, threads, uptime, clock speed, cache sizes)
- Monitor RAM and Swap usage with detailed breakdowns
- Monitor Disk utilization and transfer rates
- Monitor network utilization, transfer speeds, and interface information (Wi-Fi/Ethernet, IP addresses)
- Monitor GPU usage, video encoder/decoder, memory, and power consumption (powered by NVTOP)
- Monitor system fans
- Breakdown of resource usage by application and process
- Supports a minified summary view for simple monitoring
- Hardware-accelerated rendering for graphs to reduce CPU usage
- Built with GTK4 and Libadwaita, written in Rust

## How to Get It
Mission Center is available in the Zorin OS Software app and can also be downloaded from the official website.

[Get Mission Center](https://missioncenter.io/)

## Privacy & Notes
- Open-source application
- Developed by Mission Center Developers
- Intel GPU monitoring limited to Broadwell and later (no VRAM/power/temperature support)
- On Linux Mint/Cinnamon, launched applications may not appear in the Applications section
