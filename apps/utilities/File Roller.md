# File Roller

**Category:** Utilities → Archive Manager<br>
**Website:** [https://gitlab.gnome.org/GNOME/file-roller](https://gitlab.gnome.org/GNOME/file-roller)

Use this app as an archive manager utility for the GNOME Environment. File Roller is a graphical front-end to archiving programs like tar and zip, allowing you to create, modify, and extract archives.

## Key Features
- Create and modify archives
- View the content of an archive
- View and modify files contained within an archive
- Extract files from archives

## Supported Formats
- 7z, ACE, ALZ, AR, ARJ, CAB, CPIO
- DEB (read-only), DMG (read-only), ISO (read-only)
- JAR, EAR, WAR
- LHA, RAR, CBR
- RPM (read-only)
- TAR (with various compressions: gz, bz2, xz, zst, etc.)
- SNAP, SQSH, SIT, ZIP, and more

## How to Get It
File Roller comes installed by default on Zorin OS. It is also available in the Zorin OS Software app.

[Get File Roller](https://gitlab.gnome.org/GNOME/file-roller)
