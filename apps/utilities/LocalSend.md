# LocalSend

**Category:** Utilities → File Transfer<br><br>
**Website:** [https://localsend.org/](https://localsend.org/)

Use this app to share files without the cloud. LocalSend provides fast, private, offline file sharing across your local network, allowing you to transfer files between nearby devices securely without requiring internet access or third-party servers.

## Key Features
- Cross-platform support (Windows, macOS, Linux, Android, iOS)
- End-to-end encryption for all file transfers
- No internet required - works completely offline on your local network
- Blazingly fast transfers at maximum WiFi speed
- Zero configuration - just install and start sharing
- No account, no login, no servers needed
- Supports any file type (photos, videos, documents, text)
- PIN verification option for extra security
- Files saved to Downloads folder by default (configurable)
- Web app available for browser-based sharing

## How to Get It
LocalSend is available in the Zorin OS Software app and can also be downloaded from the official website.
