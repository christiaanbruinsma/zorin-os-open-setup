# Calculator

**Category:** Utilities → Calculator<br>
**Website:** [https://apps.gnome.org/Calculator/](https://apps.gnome.org/Calculator/)

Use this app to perform arithmetic, scientific, or financial calculations. Calculator by The GNOME Project solves mathematical equations with multiple modes for different needs.

## Key Features
- Basic mode for arithmetic operations
- Advanced mode with logarithms, factorials, trigonometric functions, complex numbers, and more
- Financial mode for interest rates, present/future value, and depreciation calculations
- Programming mode for binary, octal, decimal, hexadecimal, and bitwise operations
- Conversion mode for units, currencies, and number bases
- Keyboard mode for quick calculations

## How to Get It
Calculator comes installed by default on Zorin OS. It is also available in the Zorin OS Software app and can be downloaded from the official website.

[Get Calculator](https://apps.gnome.org/Calculator/)
