# Brave Browser

**Category:** Utilities → Web Browser<br>
**Website:** [https://brave.com/](https://brave.com/)

Use this app as a browser that prioritizes privacy and performance. Brave blocks ads and trackers by default, resulting in faster page loads and reduced data usage.

## Key Features
- Blocks third-party ads on websites (video, search, social media)
- Blocks cookie consent pop-ups
- Saves bandwidth, mobile data, battery life, and CPU usage
- Webpages load significantly faster due to ad and tracker blocking
- Shields against tracking and browser fingerprinting by default
- Built-in security features enabled by default
- Based on the open-source Chromium Web core

## How to Get It
Brave Browser is available in the Zorin OS Software app and can also be downloaded from the official website.

[Download Brave Browser](https://brave.com/)
