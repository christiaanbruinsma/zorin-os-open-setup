# Document Viewer

**Category:** Utilities → Document Viewer<br>
**Website:** [https://gitlab.gnome.org/GNOME/evince](https://gitlab.gnome.org/GNOME/evince)

Use this app to view multiple document formats. Document Viewer (Evince) aims to replace the multiple document viewers on the GNOME Desktop with a single simple application.

## Key Features
- Supports multiple document formats including PDF, PostScript, DjVu, and more
- Simple and clean interface
- Unified document viewing experience

## How to Get It
Document Viewer comes installed by default on Zorin OS. It is also available in the Zorin OS Software app.

[Get Document Viewer](https://gitlab.gnome.org/GNOME/evince)

## Privacy & Notes
- Open-source application
- Developed by The GNOME Project
- Default document viewer for GNOME-based distributions
