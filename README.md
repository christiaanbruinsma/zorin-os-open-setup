# Zorin OS - Open Setup

A reference guide to help people and organizations move toward digital autonomy with Zorin OS.

It covers recommended applications, both open-source and mainstream, alongside Zorin-specific settings to make the transition easier and lower the barrier for those interested in Zorin OS (Linux) as their daily operating system.

## Quick Start

- [Applications](./apps/README.md) - Recommended apps by category
- [Appearance Tweaks](./appearance/README.md) - Themes and visual customizations
- [Use Cases](./use-cases/README.md) - Complete setups for specific needs

## Why this guide
This guide exists because the switch to Linux should not require you to be an expert. The author shares what he uses and recommends, so anyone curious about Zorin OS can get started with confidence.

## What's in this guide
- Recommended applications, open-source and mainstream
- Zorin-specific settings and customizations
- Notes and tips for a smoother transition

**Note:** Zorin OS is based on Ubuntu/Debian and utilizes GNOME/Wayland.
